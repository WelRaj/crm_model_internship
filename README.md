# CRM Project - Main Documentation

## Overview
A high-end Enterprise CRM built with a Next.js (React) Frontend and a planned Django (Python) Backend with MySQL.

## Project Structure
- panel/: Next.js Frontend (App Router, Tailwind CSS, Lucide Icons).
- backend/: Django Backend (Planned).
- PANEL.md: Detailed frontend status and architecture.
- PROJECTS.md: Specifics on the Project Management module.
- BACKEND.md: Planned backend architecture and API endpoints.

## Tech Stack
- Frontend: Next.js 15+, Tailwind CSS v3 (JS-based for compatibility), Lucide React.
- Backend: Django, Django Rest Framework.
- Database: MySQL.
- Auth: Mobile + 6-digit OTP (Planned).
